### Part A: Input space partitioning for ratings

โมเดลข้อมูลนำเข้าสำหรับ `POST /api/ratings` ใช้ค่าฐานเป็นคะแนนจำนวนเต็ม
3 ดาว พิซซ่าที่สร้างสำหรับเทสต์ และ token ของผู้ใช้เจ้าของข้อมูล
แต่ละกรณีเปลี่ยนเพียงหนึ่งลักษณะจากค่าฐาน โดยลักษณะอื่นยังใช้ค่าฐานเดิม
ชื่อต่อไปนี้อยู่ใน `test_create_rating.py`

| ลักษณะ | กลุ่มข้อมูล | ค่าที่ใช้ทดสอบ | เทสต์ที่ครอบคลุม |
| --- | --- | --- | --- |
| C1: ค่าคะแนน | ต่ำกว่า 1 | `0` | `test_stars_out_of_range[0]` |
| C1: ค่าคะแนน | 1–5 (ฐาน) | `3` | `test_base_choice_is_saved` |
| C1: ค่าคะแนน | มากกว่า 5 | `6` | `test_stars_out_of_range[6]` |
| C2: ชนิดคะแนน | จำนวนเต็ม (ฐาน) | `3` | `test_base_choice_is_saved` |
| C2: ชนิดคะแนน | ทศนิยม | `3.5` | `test_stars_invalid_type[decimal]` |
| C2: ชนิดคะแนน | ข้อความ | `"3"` | `test_stars_invalid_type[text]` |
| C2: ชนิดคะแนน | ไม่มีฟิลด์ | ไม่ส่ง `stars` | `test_missing_stars_is_refused` |
| C3: พิซซ่า | มีอยู่จริง (ฐาน) | `pizza_id` จาก fixture | `test_base_choice_is_saved` |
| C3: พิซซ่า | ไม่มีอยู่จริง | `999999999` | `test_nonexistent_pizza_is_refused` |
| C4: Token | ของผู้ใช้เอง (ฐาน) | จาก fixture `auth` | `test_base_choice_is_saved` |
| C4: Token | ไม่มี | ไม่ส่ง header `Authorization` | `test_missing_token_is_refused` |
| C4: Token | ความยาวไม่ถูกต้อง | `token short` | `test_short_token_is_refused` |

Base choice coverage ใช้ `1 + (3−1) + (4−1) + (2−1) + (3−1) = 9` กรณี
จากกลุ่มข้อมูลตามโมเดลในใบงาน เทียบกับ all combinations จำนวน
`3 × 4 × 2 × 3 = 72` กรณี

| ข้อ | การทดลอง | ผลการทดลอง |
| --- | --- | --- |
| A1 | สร้างโมเดล C1–C4 และทดสอบค่าฐานกับคะแนน 0 และ 6 | ทั้ง 3 กรณีผ่าน: ค่าฐานได้ 201 พร้อมคะแนน 3 และ `pizza_id` ที่ส่ง; คะแนน 0 และ 6 ได้ 400 พร้อมข้อความว่าคะแนนต้องอยู่ระหว่าง 1–5 |
| A2 | เพิ่มกรณีชนิดคะแนน พิซซ่าที่ไม่มีอยู่ และ token ให้ครบ base choice coverage โดยหาข้อความผิดพลาดด้วย curl ก่อน | เทสต์สร้างคะแนนครบ 9 กรณีผ่านทั้งหมด; ทศนิยม ข้อความ ไม่มีคะแนน และพิซซ่าที่ไม่มีอยู่ได้ 400; ไม่มี token และ token สั้นได้ 401 พร้อมข้อความผิดพลาดตรงตามที่ตรวจด้วย curl |
| A3 | เปลี่ยนคะแนนเป็น 0, 1, 5 และ 6 แล้วอ่านกลับทุกครั้ง | ผ่านทั้ง 4 กรณี: 1 และ 5 ได้ 200 และบันทึกค่าใหม่; 0 และ 6 ได้ 400 โดยข้อมูลเดิมรวมถึงคะแนน 3 ดาวยังคงเดิม |
| A4 | ให้ผู้ใช้อื่นอ่าน แก้ไข และลบคะแนน แล้วให้เจ้าของอ่านกลับ | ผ่านทั้ง 3 กรณี: อ่านได้ 404, แก้ไขได้ 400, ลบได้ 400; เจ้าของอ่านกลับได้ 200 และข้อมูลตรงกับก่อนถูกพยายามเข้าถึงทุกกรณี |
